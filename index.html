Pocket Arcade Database

Every arcade game playable on the Analogue Pocket through openFPGA cores — one entry per game, with all of its versions and every platform & core that run it.

Data: openFPGA Library (core list & releases; game lists come from each core's own instance files), MAME 0.264 metadata (year, publisher, players, orientation, parent/clone grouping), genres from progettoSNAPS catver remapped to a simpler gameplay taxonomy (a game can carry several genres), simultaneous-play data from nplayers.ini. Co-op / Versus badges are derived from the category combined with simultaneous play (e.g. a “Versus” category = versus; a simultaneous beat ’em up / shooter / platformer = co-op; simultaneous sports & puzzle games = versus) — a derivation, not per-game documentation. Patreon cores are included and marked with a lock icon. Player counts are the arcade cabinet's: “(alternating)” means the players take turns instead of playing at the same time. All versions of a game (regions, revisions, bootlegs, hacks) are grouped under a single entry. “Home ports” are the home versions of the same game on consoles, handhelds and computers that also have an openFPGA core on the Pocket, matched by exact title (arcade or regional name) against the MAME software lists, plus a short curated exceptions list — a home version is an adaptation, not the arcade original. Screenshots: in-game snaps from the progettoSNAPS MAME collection, via libretro-thumbnails, with additional screenshots from Arcade Database.
